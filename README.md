# Smart Finance

Smart Finance is a personal financial management web application to help users manage income, expenses, savings, loans, and debtors.

## Features
- Record income, expenses, savings, loans, and debtors
- Dashboard with financial overview
- Form panels for data entry

## Technologies
- HTML
- CSS
